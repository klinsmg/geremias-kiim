# Geremias Kiim Hair

Site institucional da Geremias Kiim Hair — atelier de cor boutique especializado em loiros naturais e correção de cor, atendimento no Solo Concept Beauty Coworking (Santos, Lisboa).

Projeto Astro estático (sem backend), Tailwind CSS v4 e Alpine.js para interatividade mínima.

## Comandos

Todos os comandos rodam a partir da raiz do projeto:

| Comando             | Ação                                              |
| :------------------ | :------------------------------------------------- |
| `npm install`        | Instala as dependências                            |
| `npm run dev`         | Sobe o servidor de desenvolvimento local            |
| `npm run build`       | Builda o site de produção em `./dist/`              |
| `npm run preview`     | Serve o build de produção localmente antes do deploy|

## Estrutura

```
src/
├── components/   # componentes Astro (Hero, Servicos, Galeria, etc.)
├── layouts/      # layout base (Layout.astro)
└── pages/        # rotas (index.astro)
public/           # assets estáticos e fontes auto-hospedadas
```
